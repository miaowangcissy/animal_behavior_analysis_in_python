# animal_behavior_analysis_in_python

This course provides introduction into the modern approaches to ethology. We will cover main methodological approaches to quantitative analysis of animal (flies, fish, rodents and humans) through discussion of key publications.  

Students will gain practical skills in using Python for performing basic analysis of diverse behavioral data including methods from computer vision, 3D tracking, kinematic feature extraction, behavioral segmentation and classification and kinematic time series analysis.
